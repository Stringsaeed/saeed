
This weekend I tried [Pi Agent](https://pi.dev) and [Hermes Agent](https://hermes-agent.nousresearch.com).

I spent more time with Pi, and it feels like a missing piece in my software workflow.

Pi lets you assign different models to the same session. One model can implement a feature, another can review the code, and another can plan the product ahead. They all work with the same session context.

With the right setup, that can reduce costs a lot. I am still working out what that setup should be, but I think I will stick with Pi for a while.

Another project worth a look is [Tau](https://twotimespi.dev) from Hugging Face.
